NULL Handling in MySQL
----------------------

What is NULL Handling?
~~~~~~~~~~~~~~~~~~~~~~

   NULL handling is the process of identifying, checking, and managing
   NULL values in a database. It helps developers handle missing or
   unknown data correctly, preventing incorrect query results and making
   the output more meaningful and reliable.

--------------

IS NULL
~~~~~~~

   IS NULL is a comparison operator used to check whether a column
   contains a NULL value. It is useful for finding records where
   information is missing or has not been entered.

Interview Answer
~~~~~~~~~~~~~~~~

   IS NULL is a MySQL operator used to identify rows where a column
   contains a NULL value. Since NULL represents missing or unknown data,
   the ``IS NULL`` operator helps retrieve records with unavailable
   information.

--------------

IS NOT NULL
~~~~~~~~~~~

   IS NOT NULL is a comparison operator used to check whether a column
   contains a valid (non-NULL) value. It is useful for retrieving
   records where the required information is available.

.. _interview-answer-1:

Interview Answer
~~~~~~~~~~~~~~~~

   IS NOT NULL is a MySQL operator used to identify rows where a column
   has a valid value instead of NULL. It helps retrieve records that
   contain existing or available data while excluding missing values.

IFNULL()
~~~~~~~~

    ``IFNULL()`` is a MySQL function used to replace a ``NULL`` value
with another specified value. If the given expression contains ``NULL``,
the function returns the replacement value. Otherwise, it returns the
original value. It is commonly used to display meaningful output instead
of blank or missing values in query results.

Syntax
^^^^^^

.. code:: sql

   IFNULL(expression, replacement_value)

Interview Answer
^^^^^^^^^^^^^^^^

   ``IFNULL()`` is a MySQL function that checks whether an expression is
   ``NULL``. If it is ``NULL``, it returns the specified replacement
   value; otherwise, it returns the original value. It is mainly used to
   handle missing values and produce cleaner query results.

--------------

COALESCE()
~~~~~~~~~~

    ``COALESCE()`` is a MySQL function that returns the first
non-``NULL`` value from a list of expressions. It checks each expression
from left to right and stops as soon as it finds a value that is not
``NULL``. If all expressions are ``NULL``, the function returns
``NULL``.

.. _syntax-1:

Syntax
^^^^^^

.. code:: sql

   COALESCE(expression1, expression2, ..., expressionN)

.. _interview-answer-1:

Interview Answer
^^^^^^^^^^^^^^^^

   ``COALESCE()`` is a MySQL function used to return the first
   non-``NULL`` value from multiple expressions. It is useful when you
   want to check several columns or values and display the first
   available value instead of ``NULL``.

.. code:: sql

    %%sql
    
    SELECT 
    LENGTH (customer_name) as name_length,
    LOWER (customer_name) as name_lower,
    UPPER (address) as city_upper,
    SUBSTRING(TRIM(customer_name),1,5) as first_name,
    RPAD(customer_name, 15, '*') AS right_pad,
    REPLACE(customer_name, 'Ravi', 'Ravi kumar') as updated_name, 
    INSTR(address, 'Chennai') > 0 as chennai_people, 
    RIGHT(phone_number, 4) as phone_lastdigit,
    FORMAT(amount, 2) AS formatted_amount,
    REVERSE(customer_name) as reversed_name
    
    from CustomerData;
